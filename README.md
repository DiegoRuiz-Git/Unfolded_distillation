# Code for *Unfolded distillation: very low-cost magic state preparation for biased-noise qubits*

This repository presents the code used for the numerical simulations and searches in the paper *Unfolded distillation: very low-cost magic state preparation for biased-noise qubits*. 

- The folder *Repetition code simulations* corresponds to simulations of the unfolded code merged with a repetition code (Figure 5,6,15,16,17 of the paper).

- The folder *Surface code simulations* corresponds to simulations of the unfolded code merged with a surface code (Figure 8,9 of the paper).

- The folder *Toffoli Bottom-up scheme* corresponds to simulations of the preparation of a Toffoli magic state (Table I of the paper).

- The folder *Unfolded code search* corresponds to the search of the unfolded code (Appendix F of the paper).
